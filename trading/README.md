# Бэктест торговой стратегии на МосБирже

Проверка стратегии «Откат в растущем» на исторических данных MOEX ISS.
Описание логики и критериев приёмки — в [STRATEGY.md](STRATEGY.md).

Код **не отправляет биржевых заявок** и не требует торгового токена.
Он считает сигналы и статистику; решения принимает и заявки ставит человек.

## Установка

```bash
cd trading
pip install -r requirements.txt
```

Нужен доступ к `iss.moex.com` (открытый API MOEX, ключи не требуются).

## Запуск

```bash
python3 run_backtest.py                 # in-sample + out-of-sample
python3 run_backtest.py --oos-only      # только out-of-sample
python3 run_backtest.py --no-cache      # перекачать данные с нуля

python3 run_signals.py                  # режим рынка + кандидаты на сегодня
python3 run_signals.py --capital 15000  # с расчётом размера позиции
```

Первый прогон качает историю по всем бумагам доски за 12 лет — это долго
(десятки минут). Данные кэшируются в `data/`, повторные прогоны быстрые.

## Проверка кода

```bash
python3 tests/test_indicators.py    # RSI против канонического набора Уайлдера
python3 tests/test_backtest.py      # движок: look-ahead, стопы, издержки, режим
```

Тесты движка проверяют ровно те три вещи, из-за которых самодельные боты
показывают красивую историю и теряют деньги на живом счёте: сделку по цене
сигнала, стоп по цене стопа при гэпе вниз и забытые комиссии.

## Структура

```
config.yaml          все параметры стратегии и критерии приёмки
src/moex.py          загрузка MOEX ISS: котировки, дивиденды, лоты, состав доски
src/indicators.py    RSI, SMA, ATR (сглаживание Уайлдера)
src/strategy.py      правила: режим, фильтр входа, размер позиции
src/backtest.py      движок: исполнение по T+1, стопы, издержки, лотность
src/report.py        метрики и проверка критериев приёмки
run_backtest.py      прогон с walk-forward разделением
run_signals.py       сигналы на ближайшую сделку
```

## Как читать результат

Смотреть надо **только на out-of-sample**. Параметры подбираются на данных
до 2021-12-31, результат на 2022-2026 смотрится один раз.

Подкрутили параметр после того, как увидели out-of-sample — тест сгорел,
нужна новая гипотеза и новые данные. Это главный способ обмануть самого себя
и получить систему, которая работает только на истории.
